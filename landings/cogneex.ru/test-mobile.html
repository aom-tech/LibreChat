Mobile Menu Test

Open the development server at http://localhost:4321

How to test:

  1. Open the page in your browser
  2. Open Developer Tools (F12 or right-click → Inspect)
  3. Toggle device emulation (Ctrl+Shift+M or click mobile icon)
  4. Select a mobile device like iPhone or set width to less than 768px
  5. Click the burger menu (3 horizontal lines) in the top right
  6. The menu should slide in from the right
  7. Click on any menu item to close the menu
  8. Click the overlay (dark background) to close the menu
  9. Press Escape key to close the menu

Expected behavior:

  • ✅ Burger icon visible on mobile screens (< 768px)
  • ✅ Clicking burger opens slide-in menu from right
  • ✅ Burger icon animates to X when menu opens
  • ✅ Dark overlay appears behind menu
  • ✅ Body scroll is disabled when menu is open
  • ✅ Clicking menu links closes the menu
  • ✅ Clicking overlay closes the menu
  • ✅ Pressing Escape closes the menu
  • ✅ "Try for free" button appears at bottom of mobile menu
